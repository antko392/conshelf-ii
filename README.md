# Кон-Шельф II

Браузерная 3D-прогулка по подводной деревне экспедиции Жака-Ива Кусто 1963 года. Художественная реконструкция.

[Начать погружение](https://antko392.github.io/conshelf-ii/)

## Как играть

Откройте ссылку на телефоне или компьютере и нажмите «Начать погружение». На телефоне кнопки управляют движением вперёд и назад, а движение пальцем по экрану поворачивает камеру. На компьютере используйте WASD и ведите мышью с зажатой кнопкой для обзора. В меню локаций можно выбрать «Морскую звезду» и другие части деревни.

## Как обновлять

GitHub Pages раздаёт файлы из корня ветки `main`. Для обновления загрузите изменившиеся файлы веб-сборки в эту ветку с сохранением структуры каталогов. Статус публикации виден во вкладке **Actions**, а адрес игры — в **Settings → Pages**.
